# n8n: Агент сбора контактов образовательных организаций

Этот проект содержит JSON-шаблон для **n8n 1.123.18**:
- `n8n_edu_contacts_agent.json`

Он собирает контакты руководителей образовательных организаций (школы, детские сады, кружки и т.д.) и записывает их в Google Sheets.

## Что делает workflow
1. Берёт список регионов и типов организаций из ноды **Set Seeds**.
2. Формирует поисковые запросы.
3. Ищет сайты через Serper API.
4. Парсит страницы и извлекает:
   - регион,
   - вид организации,
   - название организации,
   - ФИО руководителя,
   - телефон сотовый,
   - телефон городской,
   - email.
5. Фильтрует «свежие» данные.
6. Загружает в Google Sheet через `appendOrUpdate` (без дублей по ключевым полям).

## Быстрый старт (самое важное)

### 1) Импортируйте JSON в n8n
- Откройте n8n.
- **Workflows → Import from file**.
- Выберите файл `n8n_edu_contacts_agent.json`.

### 2) Заполните ключи в ноде **Set Seeds**
Откройте ноду **Set Seeds** и заполните поля:
- `serperApiKey` → вставьте ваш ключ Serper.
- `gsheetId` → вставьте ID Google-таблицы.

Также при необходимости измените:
- `regionsCsv`
- `orgTypesCsv`
- `searchResultsPerQuery`

> Ответ на ваш вопрос «куда вставлять SERPER ключ»: **прямо в Set Seeds → `serperApiKey`**.

### 3) Подключите Google credentials
- Откройте ноду **Upsert to Google Sheets**.
- В поле Credentials выберите/создайте ваш **Google Sheets OAuth2** credential.

> Без этого шагa запись в таблицу не сработает.

### 4) Подготовьте Google Sheet
В таблице должен быть лист с именем:
- `Контакты`

Рекомендуемые заголовки столбцов:
- Регион
- Вид организации
- Название организации
- ФИО руководителя
- Телефон сотовый
- Телефон городской
- Емайл
- Источник
- Дата проверки

### 5) Запустите
- Нажмите **Execute workflow**.
- Проверьте выполнение по шагам в Execution.
- Проверьте, что строки появились в Google Sheet.

## Где что настраивается

### Set Seeds
- Основная точка настройки.
- Нода не пустая: в ней все стартовые параметры (ключи + регионы + типы организаций + лимит выдачи).

### Search (Serper)
- Берёт API ключ из `{{$json.serperApiKey}}`.

### Upsert to Google Sheets
- Берёт ID таблицы из `{{$json.gsheetId}}`.
- Пишет в лист `Контакты`.
- Режим `appendOrUpdate` защищает от дублей по ключу:
  - Регион + Вид организации + Название организации + ФИО руководителя.

## Частые проблемы

### 1) `401/403` в Search (Serper)
Проверьте:
- верно ли вставлен `serperApiKey` в **Set Seeds**,
- активен ли ваш ключ в Serper.

### 2) Ошибка в Google Sheets ноде
Проверьте:
- выбран ли OAuth2 credential,
- правильный ли `gsheetId`,
- есть ли лист `Контакты`,
- есть ли у подключенного Google-аккаунта доступ к таблице.

### 3) Ничего не записывается
Проверьте:
- что в Execution доходите до ноды **Upsert to Google Sheets**,
- что после фильтра **Filter Valid & Fresh** остаются элементы,
- уменьшите строгость фильтра или увеличьте `searchResultsPerQuery`.

## Примечание по качеству данных
Данные извлекаются автоматически из открытых источников, поэтому:
- часть контактов может требовать ручной валидации,
- рекомендуется периодически повторный прогон workflow,
- при необходимости добавьте отдельную проверку телефонов/email перед финальной записью.
